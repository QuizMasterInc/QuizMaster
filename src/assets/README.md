# Assets Directory

## Purpose
This directory contains team member photos and visual assets for all contributors who have worked on the QuizMaster project throughout its development history.

## Instructions for New Team Members
To add yourself to the team:

1. **Prepare Your Photo**: Get a professional headshot photo and convert it to WebP format with approximately 400x400 pixel resolution
2. **Add to Assets**: Place your `firstname.webp` file in this directory
3. **Update Contact Component**: Go to `src/components/contact/Contact.jsx` and add your information following the existing team member format
