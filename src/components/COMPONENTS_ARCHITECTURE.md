# Components Directory

## Overview
This directory contains all React components organized by feature. Each folder represents a different part of the QuizMaster application.

## Directory Structure

### Core Pages
- **`home/`** - Landing page and hero section
- **`about/`** - About page content
- **`contact/`** - Team member information and contact details
- **`login/`** - User authentication and sign-in

### Navigation & Layout
- **`navbar/`** - Main navigation bar
- **`ui/`** - Reusable UI components (buttons, cards, containers)
- **`icons/`** - Icon components used throughout the app

### Quiz Features
- **`quiz/`** - Quiz-taking interface and logic
- **`quizselect/`** - Browse and select quizzes to take
- **`customquiz/`** - Create and edit custom quizzes
- **`flashcards/`** - Flashcard study system

### User Management
- **`dashboard/`** - User dashboard showing stats and progress
- **`settings/`** - User preferences and account settings

### Additional Features
- **`chatbot/`** - AI chatbot for help and assistance
- **`developer/`** - Admin tools and developer utilities

## Getting Started
When working with components:
1. Find the feature you're working on in the directory list above
2. Each folder contains the main component file and any related sub-components
3. Shared components like buttons and icons are in the `ui/` and `icons/` folders
4. Import components using relative paths from their specific directories
