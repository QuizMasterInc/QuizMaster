# Login Components

## Purpose
Contains components for user authentication including login, registration, and account management.

## What's Inside
This directory handles all user authentication features:
- **User Registration**: Creating new accounts with email and password
- **User Login**: Signing in existing users
- **Password Recovery**: Resetting forgotten passwords via email
- **Account Management**: Updating user profiles and passwords

## How It Works
The login components use Firebase Authentication for secure user management and integrate with the AuthContext to share user data across the entire application.
