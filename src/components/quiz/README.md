# Quiz Components

## Purpose
Contains the components that handle the actual quiz-taking experience, from loading questions to submitting answers.

## Components

### QuizActivity.jsx
The main component that manages the entire quiz session including loading questions, tracking time, and handling quiz submission. This is the page users see when actively taking a quiz.

### CustomQuizActivity.jsx
Similar to QuizActivity but specifically handles custom quizzes created by users or teachers. Manages the flow for user-created quiz content.

### Question.jsx
Displays individual quiz questions and handles user answer selection. Supports different question types like multiple choice, true/false, and essay questions.
