# Developer Components

## Purpose
Contains admin tools for developers and content managers to add questions to the default question bank.

## Access
Only users with developer or admin roles can access these components. They're protected by authentication and permission checks.

## What It Does
Provides a web interface for adding new questions to the system's default question bank. These questions are then available for use in system-generated quizzes.

## How It Works
Developers can create questions with multiple choice answers, assign them to categories (like Math, Science, History), and set difficulty levels. The questions are saved to Firebase and become part of the question pool for automatic quiz generation.
