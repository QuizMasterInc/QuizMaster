# Home Components

## Purpose
Contains the main landing page components that users see when they first visit QuizMaster.

## What's Inside
- **Hero Section**: Main welcome message and introduction to QuizMaster
- **Feature Overview**: Cards showing available features like quizzes and flashcards
- **Navigation Links**: Buttons and links to guide users to different parts of the app

## How It Works
The home page shows different content based on whether the user is logged in or not, and provides easy navigation to the main features of the application.
