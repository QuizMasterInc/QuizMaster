# Quiz Select Components

## Purpose
Contains components that let users browse and choose which quiz they want to take, including both default quizzes and custom user-created ones.

## Components

### SelectQuiz.jsx
The main quiz selection page that shows different ways to choose a quiz. Users can select by category, generate random quizzes, or browse custom quizzes.

### QuizSelectButton.jsx
Shows quiz categories (like Math, Science, History) as clickable buttons. Users can pick a subject and customize difficulty level and number of questions.

### RandomQuizSelect.jsx
Generates random quizzes by mixing questions from different categories. Users can set preferences for how many questions and which subjects to include.

### customquizselect/AllTeacherQuizzes.jsx
Displays all custom quizzes created by teachers and other users. Users can search, filter by tags, and select public quizzes to take.
