# Tests Directory

## Purpose
Contains automated tests to ensure code quality and architecture standards for the QuizMaster application.

## Test Files

### ArchitectureGuards.test.jsx
Tests that prevent code quality issues like excessive micro-components and enforce architectural standards. Checks for components that are too small, missing documentation, and proper file organization.

### ConsolidationSuccess.test.jsx
Validates that architecture consolidation work was completed successfully. Verifies that component directories were reduced from 29+ to a manageable number and confirms the cleanup eliminated component proliferation.
